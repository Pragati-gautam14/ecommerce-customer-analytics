# Power BI model & DAX measures

Import the CSVs in this folder (`fact_sales.csv` is generated by `python src/run_pipeline.py`) and build a star schema:

```
dim_date[date_key]        1 ── *  fact_sales[date_key]
dim_customer[customer_id] 1 ── *  fact_sales[customer_id]
dim_product[stock_code]   1 ── *  fact_sales[stock_code]
```
Mark `dim_date` as the date table.

```DAX
Total Revenue      = SUM ( fact_sales[line_revenue] )
Orders             = DISTINCTCOUNT ( fact_sales[invoice_no] )
Customers          = DISTINCTCOUNT ( fact_sales[customer_id] )
Avg Order Value    = DIVIDE ( [Total Revenue], [Orders] )
Revenue LM         = CALCULATE ( [Total Revenue], DATEADD ( dim_date[date_key], -1, MONTH ) )
MoM Growth %       = DIVIDE ( [Total Revenue] - [Revenue LM], [Revenue LM] )
Revenue YTD        = TOTALYTD ( [Total Revenue], dim_date[date_key] )
Revenue Share %    = DIVIDE ( [Total Revenue], CALCULATE ( [Total Revenue], ALL ( dim_customer[segment] ) ) )
Repeat Customers   =
    COUNTROWS ( FILTER ( VALUES ( fact_sales[customer_id] ),
        CALCULATE ( DISTINCTCOUNT ( fact_sales[invoice_no] ) ) >= 2 ) )
Repeat Rate %      = DIVIDE ( [Repeat Customers], [Customers] )
At-Risk Revenue    = CALCULATE ( [Total Revenue], dim_customer[segment] = "At Risk (High Value)" )
```

Suggested pages: **Overview** (KPI cards + monthly trend), **Customers** (RFM segment matrix with slicer on segment/country), **Products** (Pareto + top SKUs), **Retention** (cohort matrix).
